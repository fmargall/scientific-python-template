# Scientific Python Template

A [Copier](https://copier.readthedocs.io/) template for scientific Python packages: uv,
ruff, pyright, pre-commit, a tested CI, releases to PyPI with trusted publishing, citation
metadata ready for Zenodo, and projects kept up to date with `copier update`.

The documentation follows [Diátaxis](https://diataxis.fr/): learn with the tutorials,
solve a task with the how-to guides, look up a fact in the reference, and understand the
choices in the explanation.
